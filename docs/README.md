# ChangeFreeze — quiet window for shipping

Same story as the project home page.

1. Set a quiet window.
2. Hermes asks before it ships during that window.
3. Everyday work still runs.

You end the window with `/freeze`. The helper cannot end it for you. Code cells are checked for the same ship words. A command built from pieces can still get through. This is not a sealed box.
